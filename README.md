Sunrise Courier — a dawn delivery flight game: fly a courier plane through target rings over a mountain valley, manage throttle and fuel, and land back on runway 27. Three missions, a lit cockpit HUD (altitude, speed, heading), and synthesized WebAudio sound. Runs offline in a desktop browser from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and fly with keyboard and mouse (W/S throttle, arrows/A/D pitch and bank, mouse steer, Space speed brake).
